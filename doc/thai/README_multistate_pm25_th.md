# คู่มือการวิเคราะห์ Multistate Model: ผลของ PM2.5 ต่อการเกิดโรคและการเสียชีวิต (ข้อมูล THFT)

คู่มือนี้อธิบายการสร้างแบบจำลองหลายสถานะ (multistate model) แบบ **illness–death model**
เพื่อศึกษาว่าการสัมผัสฝุ่น PM2.5 สัมพันธ์กับ (1) การเกิดโรค (2) การเสียชีวิตก่อนเกิดโรค
และ (3) การเสียชีวิตหลังเกิดโรค อย่างไร โดยใช้ Python และ `scikit-survival`

โค้ดฉบับเต็มที่รันได้ทันทีอยู่ในไฟล์ [`thft_multistate_pm25.py`](thft_multistate_pm25.py)
(ถ้าไม่ใส่ไฟล์ข้อมูล โปรแกรมจะสร้างข้อมูลจำลองให้ทดลองก่อน)

## 1. แนวคิดของแบบจำลอง

```
              ทรานซิชัน 1 (0→1)
  [0] ปกติ  ───────────────────►  [1] เป็นโรค
     │                                 │
     │ ทรานซิชัน 2 (0→2)                │ ทรานซิชัน 3 (1→2)
     ▼                                 ▼
  [2] เสียชีวิต  ◄──────────────────────┘
```

| ทรานซิชัน | จาก → ไป | ความหมาย |
|---|---|---|
| 1 | ปกติ → เป็นโรค | อัตราการเกิดโรค (เช่น โรคทางเดินหายใจ/หัวใจและหลอดเลือด) |
| 2 | ปกติ → เสียชีวิต | อัตราการเสียชีวิตโดยยังไม่เกิดโรค |
| 3 | เป็นโรค → เสียชีวิต | อัตราการเสียชีวิตหลังเป็นโรค |

แต่ละทรานซิชันมี **Cox model ของตัวเอง** (transition-specific / cause-specific hazard)
ทำให้ PM2.5 มี hazard ratio (HR) แยกกันได้ในแต่ละเส้นทาง

**เหตุผลที่ไม่ใช้ Cox model ธรรมดา:** ถ้าวิเคราะห์เฉพาะ "การเสียชีวิต" จะมองไม่เห็นว่า PM2.5
เพิ่มการเสียชีวิตโดยตรง หรือเพิ่มผ่านการทำให้เกิดโรคก่อน

## 2. เตรียมข้อมูล

### 2.1 รูปแบบข้อมูลที่ต้องการ (1 แถว = 1 คน)

| คอลัมน์ | ชนิด | คำอธิบาย |
|---|---|---|
| `id` | int | รหัสผู้เข้าร่วม |
| `pm25` | float | ค่าเฉลี่ย PM2.5 ที่ได้รับ (µg/m³) เช่น ค่าเฉลี่ยรายปีก่อนเข้าการศึกษา |
| `age` | float | อายุเมื่อเข้าการศึกษา (ปี) |
| `male` | 0/1 | เพศชาย = 1 |
| `smoker` | 0/1 | สูบบุหรี่ = 1 |
| `ill` | 0/1 | เกิดโรคระหว่างติดตาม = 1 |
| `t_ill` | float | เวลา (ปี) จากเข้าการศึกษาถึงวันเกิดโรค; ถ้าไม่เกิดโรค = เวลาถึงเสียชีวิตหรือสิ้นสุดการติดตาม |
| `death` | 0/1 | เสียชีวิต = 1 |
| `t_death` | float | เวลา (ปี) จากเข้าการศึกษาถึงเสียชีวิตหรือสิ้นสุดการติดตาม |

> ถ้าข้อมูล THFT ใช้ชื่อคอลัมน์ต่างจากนี้ ให้ `rename` ก่อน หรือแก้ตัวแปร `COVARIATES` ในโค้ด
> ตัวแปรกวน (confounders) อื่น ๆ เช่น BMI, รายได้, ภูมิภาค, เขตเมือง/ชนบท ควรเพิ่มเข้าไปด้วย

### 2.2 ตรวจสอบคุณภาพข้อมูล

1. `t_ill <= t_death` ทุกแถว
2. ถ้า `ill = 0` ต้องได้ `t_ill == t_death`
3. ไม่มีค่าเวลาเป็น 0 หรือติดลบ
4. กรณีเกิดโรคและเสียชีวิต **วันเดียวกัน** โค้ดจะเลื่อนวันเกิดโรคให้เร็วขึ้นครึ่งวัน (ดูฟังก์ชัน `prepare`)
5. แปลง PM2.5 เป็นหน่วย **ต่อ 10 µg/m³** (`pm25_10 = pm25 / 10`) เพื่อให้แปลผล HR ง่าย

## 4. สร้างชุดข้อมูลของแต่ละทรานซิชัน

ใช้แนวทาง **clock-reset (semi-Markov)**: เวลาของทรานซิชัน 3 เริ่มนับใหม่ตั้งแต่วันที่เกิดโรค
(เหมาะกับ scikit-survival ซึ่งยังไม่รองรับข้อมูลแบบ start–stop / left truncation)

```python
def make_transitions(df):
    # ทรานซิชัน 1: ปกติ -> เป็นโรค  (ทุกคนอยู่ในความเสี่ยง)
    t1 = df[COVARIATES].copy()
    t1["time"] = df["t_ill"]
    t1["event"] = df["ill"] == 1

    # ทรานซิชัน 2: ปกติ -> เสียชีวิต  (ทุกคน; คนที่เกิดโรคถือว่า censored ณ วันเกิดโรค)
    t2 = df[COVARIATES].copy()
    t2["time"] = df["t_ill"]
    t2["event"] = (df["ill"] == 0) & (df["death"] == 1)

    # ทรานซิชัน 3: เป็นโรค -> เสียชีวิต  (เฉพาะคนที่เกิดโรค)
    sick = df[df["ill"] == 1]
    t3 = sick[COVARIATES].copy()
    t3["age"] = sick["age"] + sick["t_ill"]      # อายุ ณ วันเกิดโรค
    t3["time"] = sick["t_death"] - sick["t_ill"] # เวลานับจากวันเกิดโรค
    t3["event"] = sick["death"] == 1
    return {"0->1": t1, "0->2": t2, "1->2": t3}
```

**สิ่งที่ต้องตรวจ:** จำนวนเหตุการณ์ในแต่ละทรานซิชัน ควรมีอย่างน้อยประมาณ 10–20 เหตุการณ์
ต่อ 1 ตัวแปรในแบบจำลอง ถ้าน้อยกว่านี้ให้ลดจำนวนตัวแปร หรือใช้ `CoxnetSurvivalAnalysis` (penalized)

## 5. สร้าง Cox model แยกแต่ละทรานซิชัน

```python
from sksurv.linear_model import CoxPHSurvivalAnalysis
from sksurv.util import Surv

models = {}
for name, d in trans.items():
    y = Surv.from_arrays(event=d["event"], time=d["time"])
    models[name] = CoxPHSurvivalAnalysis(ties="efron").fit(d[COVARIATES], y)

hr = pd.DataFrame({n: np.exp(m.coef_) for n, m in models.items()}, index=COVARIATES)
print(hr)
```

### ช่วงความเชื่อมั่น 95% (bootstrap)

`scikit-survival` ไม่คำนวณ standard error ให้ จึงใช้ bootstrap (สุ่มแถวซ้ำ 200–1000 รอบ
แล้วใช้ percentile ที่ 2.5 และ 97.5) — ดูฟังก์ชัน `bootstrap_hr` ในไฟล์โค้ด

> ถ้าต้องการ p-value และ SE แบบ Wald โดยตรง ใช้ `lifelines.CoxPHFitter` กับชุดข้อมูลเดียวกันได้

## 6. การแปลผล (ตัวอย่างจากข้อมูลจำลอง)

| ตัวแปร | 0→1 ปกติ→โรค | 0→2 ปกติ→ตาย | 1→2 โรค→ตาย |
|---|---|---|---|
| PM2.5 (ต่อ 10 µg/m³) | **1.28** (1.21–1.35) | **1.19** (1.05–1.33) | **1.14** (1.05–1.26) |
| อายุ (ต่อ 1 ปี) | 1.03 | 1.02 | 1.04 |

ตัวอย่างการเขียนผล:

> "PM2.5 ที่เพิ่มขึ้นทุก 10 µg/m³ สัมพันธ์กับอัตราการเกิดโรคที่สูงขึ้น 28% (HR 1.28, 95% CI 1.21–1.35)
> อัตราการเสียชีวิตโดยไม่เกิดโรคสูงขึ้น 19% (HR 1.19, 95% CI 1.05–1.33) และในผู้ที่เกิดโรคแล้ว
> อัตราการเสียชีวิตสูงขึ้น 14% (HR 1.14, 95% CI 1.05–1.26) หลังปรับด้วยอายุ เพศ และการสูบบุหรี่"

**ข้อควรระวัง:** HR ของแต่ละทรานซิชันเป็น *cause-specific hazard ratio* ไม่ใช่ความเสี่ยงสะสม
(cumulative risk) โดยตรง ถ้าต้องการบอก "ความน่าจะเป็น" ให้ใช้ขั้นตอนที่ 7

## 7. ความน่าจะเป็นที่จะอยู่ในแต่ละสถานะ (state occupation probabilities)

เนื่องจากเป็นแบบ semi-Markov จึงใช้ **การจำลอง Monte Carlo**:
สุ่มเวลาเกิดเหตุการณ์จากเส้นโค้ง survival ของแต่ละทรานซิชัน แล้วนับสัดส่วนคนในแต่ละสถานะ
ณ เวลาที่สนใจ (ดูฟังก์ชัน `state_probabilities`)

```python
base = {"age": 50, "male": 1, "smoker": 0}
for pm in (15, 45):  # เปรียบเทียบ PM2.5 ต่ำ vs สูง
    p = state_probabilities(models, {**base, "pm25_10": pm / 10}, times=[1, 3, 5, 10])
    print(p)
```

ตัวอย่างผล (ชายอายุ 50 ปี ไม่สูบบุหรี่, ที่ 10 ปี):

| PM2.5 | P(ปกติ) | P(เป็นโรค) | P(เสียชีวิต) |
|---|---|---|---|
| 15 µg/m³ | 0.63 | 0.22 | 0.16 |
| 45 µg/m³ | 0.41 | 0.30 | 0.29 |

ผลต่างของ P(เสียชีวิต) ระหว่างสองระดับ PM2.5 คือ **risk difference** ที่สื่อสารกับผู้กำหนดนโยบายได้ง่าย
(อย่าทำนายเกินช่วงเวลาติดตามสูงสุดของข้อมูล)

## 8. ประเมินแบบจำลอง

1. **C-index** ของแต่ละทรานซิชัน (`concordance_index_censored`) — 0.5 = เดาสุ่ม, 1 = สมบูรณ์
2. **Time-dependent AUC** (`sksurv.metrics.cumulative_dynamic_auc`) ที่ 1, 3, 5 ปี
3. **Proportional hazards assumption** — ตรวจด้วย Schoenfeld residuals
   (`lifelines.CoxPHFitter.check_assumptions`) ถ้าไม่ผ่านให้แบ่งชั้น (strata) หรือใส่ interaction กับเวลา
4. **ความสัมพันธ์ไม่เป็นเส้นตรง** — ลองใส่ PM2.5 แบบ spline หรือแบ่งเป็น quartile แล้วดูแนวโน้ม

## 9. ข้อจำกัดและการวิเคราะห์ความไว (sensitivity analysis)

| ประเด็น | ข้อแนะนำ |
|---|---|
| PM2.5 เปลี่ยนตามเวลา | ถ้ามีค่ารายปี ควรใช้ข้อมูลแบบ start–stop (time-varying covariate) ซึ่ง scikit-survival ยังไม่รองรับ → ใช้ `lifelines.CoxTimeVaryingFitter` หรือ R (`survival` + `mstate`) |
| Markov vs semi-Markov | ลองแบบ clock-forward (เวลานับจากเข้าการศึกษา) ใน R `mstate` แล้วเปรียบเทียบผล |
| การวัด PM2.5 คลาดเคลื่อน | ใช้ค่าเฉลี่ยหลายช่วง (1, 3, 5 ปี) หรือแหล่งข้อมูลต่างกัน (สถานีตรวจวัด vs ดาวเทียม) |
| ตัวแปรกวน | ปรับด้วยปัจจัยเศรษฐกิจสังคม ภูมิภาค ฤดูกาล การสูบบุหรี่ |
| ข้อมูลสูญหาย | ใช้ multiple imputation แทนการตัดแถวทิ้ง |

### ทางเลือกใน R (มาตรฐานสำหรับ multistate)

```r
library(mstate); library(survival)
tmat  <- trans.illdeath(names = c("ปกติ", "เป็นโรค", "เสียชีวิต"))
msdat <- msprep(time = c(NA, "t_ill", "t_death"), status = c(NA, "ill", "death"),
                data = thft, trans = tmat, keep = c("pm25_10", "age", "male", "smoker"))
msdat <- expand.covs(msdat, c("pm25_10", "age", "male", "smoker"))
fit <- coxph(Surv(Tstart, Tstop, status) ~ pm25_10.1 + pm25_10.2 + pm25_10.3 +
               age.1 + age.2 + age.3 + male.1 + male.2 + male.3 +
               smoker.1 + smoker.2 + smoker.3 + strata(trans), data = msdat)
summary(fit)   # HR + 95% CI ของแต่ละทรานซิชัน (clock-forward)
```
